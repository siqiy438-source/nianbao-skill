# report.json 格式

`build.py` 读这个文件排 PDF。完整的真实例子见 `示例-美的2024.json`，先照着它看一遍再写。

## 目录
1. 顶层字段
2. 章节骨架（固定 10 章 + 词典）
3. 块类型
4. 图表：什么数据用什么图
5. 文字小标记
6. 排版经验

---

## 1. 顶层字段

```json
{
  "meta": {"company": "美的集团", "full_name": "美的集团股份有限公司", "code": "000333.SZ ｜ 0300.HK",
           "year": 2024, "made": "2026 年 9 月", "source": "美的集团 2024 年年度报告 第二节、第三节",
           "page_note": "文中「第 N 页」是年报页脚上印的页码", "method": "刘总《轻松读年报》第一讲"},
  "cover": {"headline": "封面一句话结论（25 字以内最好）", "sub": "两三句展开：最重要的数字 + 最大的优点 + 最要盯的事",
            "kpis": [{"label": "营业收入", "value": "4,071.5", "unit": "亿", "delta": "比上年 [[+9.4%]]"}]},
  "summary": {"title": "一页看懂", "qa": [{"q": "公司是干什么的", "a": "…"}],
              "checkup": {"level": "过关", "text": "排雷和体检的一句话结论：审计、担保、质押、净现金、毛利率、ROE 里最要紧的两三个数"},
              "blocks": [{"type": "verdict", "...": "..."}],
              "watch": [{"t": "最要盯的事（短）", "x": "一两句为什么"}]},
  "chapters": [{"num": "00", "kicker": "第二节 …", "title": "先看成绩单", "lead": "本章结论", "blocks": []}],
  "glossary": [{"term": "扣非净利润", "plain": "一句大白话"}],
  "calc": [{"n": "26.4%", "how": "怎么算出来的"}],
  "endnote": "尾注：方法、资料、页码说明、不构成投资建议"
}
```

- `cover.kpis` 放 4 个；`summary.qa` 正好 5 个（刘总的五个问题）；`summary.watch` 放 3 个。
- `summary.checkup`：第二、三讲的体检结论，一行。`level` 写 过关 / 留意 / 有雷；`text` 两行以内，点名最要紧的两三个数（比如「审计标准无保留、没有对外担保、实控人没质押；净现金 52 亿是净利润 3.4 倍；毛利率 19% 偏低」）。
- `meta.doc_short` / `meta.doc_name`：读半年报时写 `"半年报"` / `"半年度报告"`，封面、页脚、来源标注会跟着改；读年报不用写。
- `calc`：报告里凡是**自己算出来**、原文里找不到的数（合计、差额、比率、占比），都登记在这里并写清算式。`check.py` 会把没登记、又在原文找不到的数挑出来。

## 2. 章节骨架

| num | title（可以按公司改措辞） | kicker 写对应的年报章节 | 主要内容 |
|---|---|---|---|
| 00 | 先看成绩单 | 第二节 公司简介和主要财务指标 | 规定动作：营收、扣非、季度、现金流、非经常性损益、ROE；营收、扣非、现金流三个同比方向是否一致（第三讲） |
| 01 | 公司是干什么的 | 第三节「行业情况」「主营业务分析」 | 我是谁（原话→说人话）、收入构成、业务表、规模 |
| 02 | 过去一年干得怎么样 | 第三节「主营业务分析」 | 各业务增速、国内海外、毛利率、费用、为什么是这个数 |
| 03 | 行业怎么样，对手是谁 | 第三节「行业情况」 | 行业规模和增速、公司占多少、份额排名、对手、成长空间 |
| 04 | 凭什么赢 | 第三节「核心竞争力分析」 | 研发、激励、分红回购、说到做到、效率 |
| 05 | 未来怎么走 | 第三节「未来发展的展望」 | 战略翻成大白话、明年要干的事、有无业绩指引、**我们的推测** |
| 06 | 先排雷 | 重要事项 · 股份变动及股东情况 · 审计报告 | 第二讲：审计意见、承诺、关联交易、担保；第三讲：实控人质押、高送转、增发。**一张体检表** + 有问题的逐条展开 |
| 07 | 三张表体检 | 财务报告：合并资产负债表、利润表、现金流量表、所有者权益变动表 | 第二讲：净现金（按刘总的口径列算式）、资产负债率、流动比率、带「其他」的科目、应收账龄；营收 vs 利润增速、投资收益占比、归母 vs 扣非；经营现金流 ÷ 净利润、自由现金流、利润涨现金不涨；第三讲：未分配利润 vs 分红、库存股用途。**一张体检表** + 图 |
| 08 | 毛利率和净资产收益率 | 财务分析（第三讲） | 毛利率高低和走势（30% / 15%）；扣非加权 ROE 几年走势（8% / 15% / 30%）；ROE 拆成净利率 × 周转 × 杠杆，翻成大白话；**一张体检表** + 走势图 |
| 09 | 风险和要追问的问题 | 带着问题读 | 要盯 / 留意 / 放心，每条带「调研可以问」；06–08 章查出来的问题汇总到这里 |

每章都要有：`lead`（本章结论，一两句，用 `==…==` 标出最关键的半句）＋至少一张图或一组数字卡片。「刘总读法」提示（`tip`）大部分章节放一个，全篇 4–7 个就够；版面紧的章可以省，别让一个提示框单独占一页。

年报缺内容时的替代做法（直说「年报没写」，再用手上有的数）：
- **没有份额、排名、行业规模**（小公司常见）：第 03 章用下游行业的量代替（比如风电装机量、汽车产量），或用「公司国内收入 ÷ 下游数量」粗算单价和规模，写清楚是粗算；不画份额图，改画下游行业的走势或公司国内/海外结构。
- **没点名对手**：写常识里的对手，标「年报外，待核实」。
- **没有分红、激励**：去第一、四、六节找（见 SKILL.md 第一步的表）；真没有就写「没有」，这本身就是信息。
- **ROE、毛利率不够 5 年**（一份年报只有 3 年）：公司文件夹里有往年年报，就用 `extract.py --as 2022年报` 导出它的第二节拼成 5 年；没有就画 3 年，在章里写「刘总要看 5 年，补上 20XX 年年报再跑一次」，交付时提醒用户。
- **半年报**：没有审计（体检表写「未经审计」，判留意）；没有分季度表（环比写「半年报看不到」）；ROE 是半年的数，只和去年同期比，不和全年比。
- **净现金要算存货吗**：默认不算（刘总说要看附注里是什么货再打折，没有统一折扣）；写明「存货没算，偏保守」。

## 3. 块类型

| type | 字段 | 用途 |
|---|---|---|
| `p` | `text` `src?` | 正文段落，三四行以内 |
| `h` | `text` `src?` | 章内小标题 |
| `kpis` | `cols?` `items[{label, value, unit?, delta?, dir?, note?, src}]` | 数字卡片，一行 2–4 个（`cols`），多了自动折成两行；`value` 只放数字，单位放 `unit` |
| `chart` | 见第 4 节 | 图 |
| `cols` | `items[块, 块]` | 两块并排（两张图、图＋卡片） |
| `table` | `head[]` `rows[][]` `align?` `widths?` `em?[行号]` `note?` `src?` | 表格；`align` 用 l/r/c；`em` 标出要强调的行 |
| `quote` | `orig` `plain` `src` | 左边「年报原话」、右边「说人话」 |
| `tip` | `text` `tag?` | 「刘总读法」提示框 |
| `callout` | `title` `text` | 粗线开头的一段重点分析 |
| `list` | `style: dots/nums` `items[文字 或 {t, x, src}]` | 列表 |
| `flags` | `items[{level, title, text, ask?, src}]` | 风险清单：`level` 用 要盯/留意/放心；第 07 章对答案用 应验/更差/好转/对了/推错/新情况/待看。`ask` 显示为「调研可以问：…」 |
| `compare` | `items[{said, did, verdict: 做到了/进行中/没做到, src}]` | 说到做到对照表 |
| `verdict` | `title` `items[{label, value, note}]` `basis`（文字或列表） | 深色的「明年怎么看」判断卡 |
| `checkup` | `title?` `items[{item, value, note?, rule, level, src}]` `note?` | 体检表（06–08 章）：查什么｜这家公司｜刘总的标准｜判断。`level` 用 过关 / 留意 / 危险；`rule` 写刘总的标准原意（不核对数字）；`value` 写这家公司的数，`note` 补半句为什么 |
| `pagebreak` | | 强制换页（很少用） |

`src` 统一写「第48页」「第12–14页」「第11、48页」这种（页脚页码）；原文没有、是算的就写「计算」。引用别的报告时加前缀：「半年报第6页」「2024 年报第30页」。分类名太长时可以用 `\n` 折成两行。

## 4. 图表：什么数据用什么图

`chart` 的通用字段：`kind` `title` `sub`（单位/口径）`categories[]` `series[{name, data[], color?}]` `note?` `src` `height?` `decimals?` `labelUnit?`。

| 数据的用处 | kind | 专属字段 | 例子 |
|---|---|---|---|
| 几年、几个季度的大小 | `bar` | `highlight`（强调哪一根，其余变浅）、`dimIdx`（把某几根变浅）、`band: {from, to, label?}`（铺一条浅色横带，比如「我们推的区间」，数值写进 `sub`）、`min` | 营收三年、每季度现金流、全年会落在哪 |
| 两三个同单位的系列比较 | `bar`（多系列） | 自动出图例 | 净利润 vs 经营现金流 |
| 走势 | `line` | `labelAll`、`area`、`min`/`max`、`band` | ROE 三年、毛利率走势 |
| 构成（最多 6 块） | `donut` | `center: {value, label}` | 收入按业务分 |
| 两年结构对比 | `stack100` | 数据是百分比，每行加起来 100 | 国内/海外占比 2023 vs 2024 |
| 增速、变化（有正有负） | `diverge` | `highlightIdx` + `refIdx` 改成强调模式 | 各业务增速；费用增速 vs 营收增速 |
| 排名、份额、规模 | `barh` | `tags`（每条后面的小字，如「第1」「+7.6%」）、`highlightIf: {gte: 30}`、`highlightIdx`、`rightPad` | 份额排名、各品类市场规模 |

06–08 章常用的图：
- 净现金怎么算出来的：`diverge`，每一项加了多少、减了多少（`labelUnit: " 亿"`），或者直接用表格列算式。
- 利润 vs 经营现金流几年：`bar` 两个系列（00 章已有的话，07 章画自由现金流或「现金流 ÷ 净利润」的 `line`）。
- 资产负债率、毛利率、ROE 几年：`line`，`labelAll`；ROE 用 `band: {from: 10, to: 20, label: "理想区"}` 铺出「15% 上下 5 个点」（`line` 和 `bar` 都支持 `band`），`sub` 里写清标准。
- 家底构成（现金、应收、存货、固定资产……）：`donut`，最多 6 块。

规矩（来自 dataviz 规范，脚本已经做了大部分）：
- **全篇至少要有柱状图、折线图、环形图各一张**（用户点名要的），一般 10–16 张图。
- **不用双纵轴。**单位不同的两组数，拆成两张图并排放（`cols`）。
- 环形图最多 6 块，小的合并成「其他」；只有两块的构成别画饼，用 `stack100` 或数字卡片。
- 一张图讲一件事，`title` 直接写结论（「费用涨得比收入快」），`sub` 写单位。
- 版式是 kami（紙）：墨蓝点缀，其余是暖灰。**涨跌按 A 股习惯红涨绿跌**，用户要求颜色淡一些：文字用豆沙红 `#a9564b`、松绿 `#44785a`，增速条用浅砖红、浅灰绿（脚本已设好）。费用、成本、库存这类「涨了不是好事」的，用强调模式（`highlightIdx` 标出要看的那条，`refIdx` 标出作参照的营收），别让读者把红色当成好消息。
- 有 `title` 的图自动编号「图 1、图 2……」；紧跟在小标题 `h` 下面、不写 `title` 的图不编号，但最好都写上 `title`。
- 数字不要每个点都标满，脚本默认只在柱顶、线的首尾标数。

## 5. 文字小标记

- `**加粗**`
- `==强调色==`：每章 lead 里标最关键的半句
- `[[+9.4%]]`、`[[−7.6%]]`：自动上色，红涨绿跌（淡色；按第一个字符是 + 还是 −）

## 6. 排版经验

- 图、卡片、判断卡、并排块都不会被拆到两页；放不下就整块挪到下一页，前一页会空出一截。**看预览时发现大块空白，就调整块的顺序**（把能跨页的表格、段落挪到空白处前面），或者把某张图的 `height` 调小。
- 一章写得太长（超过两页）就删重复的话；整份报告 16–20 页为宜（00–05 章 10–12 页，06–08 章 5–6 页），超过 22 页要删。
- `lead` 控制在两行、`p` 控制在四行以内，长了拆成列表或表格。
- 表格第一列都很短（8 个字以内）时自动不换行；列宽不合适可以用 `widths: ["18%", "…"]`。
